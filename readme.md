# Ecommerce Backend
## Setup Instructions

#### Install All Packages
I have created a requirement file with the name of requirements.txt.
Please run the below command to install the packages

```bash
pip install -r requirements.txt
```

#### Script to Insert Sample Data
I have created the schema for MySql databases and a seeder file to create and populate the database files
